# 你好，我是做实证的卡卡

专注经管实证研究：选题、研究设计和 Stata 实证操作。7 年科研辅导经验，服务经管方向的本科生、研究生、博士生和高校老师。

**个人主页：[kaka-stata.github.io](https://kaka-stata.github.io/)**，服务内容、合作流程和咨询方式都在这里。

## 公众号：卡卡 stata 实证研究

我在公众号里分享这些内容：

- **选题推荐**：从最新政策、热点事件和期刊文章里，找出能做实证的选题
- **方法与技巧**：机制分析、异质性分析、内生性处理、DID、稳健性检验怎么做、怎么写
- **论文拆解与 Stata 操作**：把代表性的实证论文拆开，讲清楚变量怎么测、模型怎么设
- **科研故事**：辅导过程中，同学们真实遇到的问题和我的解决办法

## 我能帮你做的事

- 论文选题与研究设计
- Stata 实证操作与数据分析
- 实证结果修改与答疑

选题没头绪、实证做不下去、结果不显著、离 DDL 越来越近，都可以来聊聊。不用准备很多，把你现在遇到的困难告诉我就行，就像找学长聊一样。
